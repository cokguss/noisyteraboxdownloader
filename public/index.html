30 video masih terkunci. Punya akun TeraBox? Tempel cookie sesi (login) Anda untuk membukanya. Tersimpan hanya di browser ini.

Cara mengambil cookie & csrfToken sesi login

1 · Cookie sesi login (BDUSS)

  1. Buka terabox.com dan login ke akun Anda.
  2. Tekan F12 > pilih tab Console. (Kalau tempel ditolak, ketik allow pasting dulu lalu Enter.)
  3. Tempel baris ini, lalu tekan Enter:
    copy(document.cookie)
  4. String cookie otomatis tersalin ke clipboard.
  5. Pastikan hasilnya memuat BDUSS=. Nilai ndus saja tidak cukup: server tetap dikenali sebagai tamu, dan video tetap terkunci.

2 · csrfToken (melalui Developer Tools)

Beberapa permintaan TeraBox menuntut token CSRF. Ada dua cara mengambilnya — pilih yang paling nyaman:

Cara cepat — Console. Masih di tab Console, tempel baris ini lalu Enter:

copy((document.cookie.match(/csrfToken=([^;]+)/) || ["", "csrfToken tidak ditemukan"])[1])

Nilai csrfToken langsung tersalin ke clipboard. Pastikan Anda sudah login — token ini hanya ada pada sesi yang login.

Cara visual — tab Application.

  1. Tekan F12 > pilih tab Application (Chrome/Edge) atau Storage (Firefox).
  2. Di panel kiri, buka Cookies > pilih https://terabox.com.
  3. Cari baris bernama csrfToken, lalu salin isinya dari kolom Value (dobel-klik nilai tersebut).

Cara pakai: gabungkan dengan cookie sesi di kolom di atas, contoh: BDUSS=…; ndus=…; csrfToken=…

Di HP (Android)

  1. Buka terabox.com di Chrome dan login.
  2. Pasang ekstensi editor cookie (mis. "Cookie Editor" di Firefox Android atau add-on setara di Chrome).
  3. Salin semua cookie terabox.com, terutama BDUSS, ndus, dan csrfToken, dalam format nama=nilai; nama=nilai.
  4. Tempel ke kolom di atas, tekan Buka.

String ini adalah kunci akun Anda - jangan dibagikan ke orang lain. Di website ini cookie hanya tersimpan di browser Anda sendiri dan dipakai untuk mengambil tautan unduh atas nama akun Anda.

Kebijakan Privasi

Terakhir diperbarui · 25 September 2026

Ringkasan singkat

Noisy TeraBox adalah alat unduh tanpa akun. Kami tidak menyimpan file Anda, tidak memasang pelacak, dan tidak menjual data apa pun. Sebagian besar proses terjadi langsung antara browser Anda dan server TeraBox — cukup sidik jari jaringan.

Data yang diproses saat mengambil file

  • Link yang Anda tempel. Hanya dipakai untuk membaca isi link berbagi dan menautkan alamat unduh; tidak disimpan permanen di server kami.
  • Cookie sesi (opsional). Bila Anda menempel cookie login, string itu disimpan hanya di localStorage browser Anda dan dikirim hanya ke server TeraBox untuk membuka file yang terkunci verifikasi. Kami tidak pernah menyalinnya ke tempat lain.
  • Log teknis. Server dapat mencatat error dan ringkasan permintaan (tanpa isi file) untuk menjaga layanan tetap stabil.
  • Statistik kunjungan. Hitungan first-party yang tampil di footer — hanya jumlah sesi aktif dan total kunjungan, tanpa cookie, tanpa alamat IP, tanpa data pribadi.

Yang tidak kami lakukan

  • Tidak mengunggah, menyalin, atau memeriksa isi file Anda.
  • Tidak memakai iklan, analitik pihak ketiga, atau cookie pelacak di situs ini.
  • Tidak membagikan data Anda kepada siapa pun.

Pihak ketiga

Layanan ini bergantung pada infrastruktur TeraBox dan CDN-nya. Saat Anda mengambil file, browser atau server kami terhubung ke domain-domain tersebut, yang masing-masing memiliki kebijakan privasinya sendiri.

Ketentuan Layanan

Terakhir diperbarui · 25 September 2026

1. Persetujuan ketentuan

Dengan mengakses atau menggunakan Noisy TeraBox, Anda menyetujui ketentuan ini. Jika Anda tidak setuju dengan salah satu poin di bawah, mohon berhenti menggunakan layanan.

2. Layanan "sebagaimana adanya"

Layanan disediakan gratis, tanpa jaminan ketersediaan tanpa gangguan. Fitur, kecepatan, dan cakupan dapat berubah sewaktu-waktu karena bergantung pada server TeraBox sebagai sumber data.

3. Penggunaan yang diperbolehkan

  • Mengunduh file yang Anda miliki haknya atau yang dibagikan terbuka oleh pemiliknya.
  • Memakai cookie sesi akun Anda sendiri bila diperlukan untuk membuka file milik Anda.

4. Larangan

  • Menggunakan layanan untuk menyebarkan konten ilegal, berhak cipta tanpa izin, atau membahayakan orang lain.
  • Membebani server secara berlebihan (otomasi massal, penyalahgunaan kuota upstream).
  • Mencoba mengganggu, memindai kerentanan, atau bocor ke sistem kami di luar fungsi normalnya.

5. Batasan tanggung jawab

Kami tidak bertanggung jawab atas isi file, link yang mati, kerugian akibat ketergantungan pada layanan, atau tindakan pemilik akun TeraBox yang mencabut akses. Anda pengguna yang paling tahu hak atas file Anda.

6. Perubahan

Ketentuan ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu terpasang di halaman ini, dengan tanggal perubahan di atas.
